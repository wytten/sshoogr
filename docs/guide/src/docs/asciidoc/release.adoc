=== Releasing `sshoogr`

The build needs JDK 17 or newer to run (CI uses 21); the library itself is compiled for Java 8.

==== Clean build

`gradlew clean build`

This compiles, runs the unit tests and CodeNarc, and builds the jars and the `sshoogr` CLI distribution
(`subprojects/sshoogr/build/distributions`).

==== Integration test

`vagrant up`

`gradlew integrationTest`

==== Dependency lockfile

After changing a dependency version in `gradle.properties` or `subprojects/sshoogr/sshoogr.gradle`:

`gradlew resolveAndLockAll --write-locks`

==== Publishing

`gradlew publishToMavenLocal`

No remote repository is configured; the old Bintray/Sonatype/SDKMAN release automation was removed
because those services and credentials are no longer available.
